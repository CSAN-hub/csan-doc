# Comment se connecter à CSAN ?

Le moyen le plus simple est d'utiliser le service d'authentifaction "EGI - SSO" et se connecter via l'interface web [CSAN](https://csanhub.org/account/sign-in). Pour créer un compte il faut renseigner son adresse mail [ici](https://sso-admin.egi.eu/admin/email).

Plus d'information sur le site de la [Fédération EGI](https://www.egi.eu/intranet).
